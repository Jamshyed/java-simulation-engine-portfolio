A text-based simulation engine developed in Java as an object-oriented programming project at the University of Birmingham.

The project models a simulation in which entities interact with resources and the simulation advances through discrete time steps, called ticks.

<Features>
Object-oriented design: Uses classes, inheritance, abstract classes, interfaces and polymorphism to structure the simulation.
Entity system: Supports producers, converters and consumers that interact with simulation resources.
Command-based interaction: Parses user commands to build entities, inspect resources and control the simulation.
Simulation engine: Advances the simulation through ticks and manages changes to resources and entities.
Save and load: Supports saving simulation state and loading it again.
Resource tracking: Tracks resources throughout the simulation and supports resource visualisation.

<Technologies>
Java
Object-oriented programming (OOP)
Git and GitLab

This project strengthened my understanding of object-oriented software design, class hierarchies, abstraction, polymorphism, command parsing and state management.

I designed and implemented the simulation's classes and logic independently, applying OOP principles to build a modular system.
